# ProDani brand assets

All SVGs have the type converted to outlines: no font loading needed, safe to upload to Shopify Files or drop into theme `assets/`.
Colours: cocoa #362619 · ivory #FAF4E9 · caramel #E0A458 · toffee #8A5A24 (text-safe caramel on ivory).

## Naming

- `-reverse` = ivory ink for dark grounds. `-mono-cocoa` / `-mono-ivory` = one colour, no caramel (kraft, foil, embroidery).
- `-ivory` on stamps = ivory hairlines with transparent centre, for placing over chocolate; `-on-chocolate` includes the disc.
- PNGs are transparent except OG, profile and app icons.

## Rules that travel with the files

- Wordmark is always lowercase; caramel lives on the full stop only.
- Coin, not bare mark, when the logo stands alone on a surface. Bare `p.` only inside the squircle (app/favicon) or the seal.
- One stamp per surface. Never rotated, never over photography.
- Icons stay line-only; the box icon's dot is the only caramel in the set.
